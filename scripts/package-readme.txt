Desktop Capture

■ 起動
  dc-tray.exe をダブルクリックします。通知領域（タスクバーの右下）にアイコンが出て、
  エンジン（mixd）とキャプチャ（capd）を裏で起動し、ミキサーの画面（dc-ui）を開きます。

■ トレイのアイコン
  左クリック          ミキサーの画面を開く（開いていれば前に出す）
  右クリック          メニュー：状態の表示、再起動、ログオン時に起動、ログのフォルダー、設定ファイル、終了
  つまみの色          緑 = 動作中、黄 = 起動中・立ち上げ直し中、赤 = 起動できない、灰 = 停止

  mixd や capd が落ちたときは通知を出して自動で立ち上げ直します。短い間に 4 回続けて落ちたら
  あきらめて赤になります（ログを見て、メニューの「再起動」で戻せます）。

■ ログオン時の起動
  メニューの「ログオン時に起動」にチェックを付けます（管理者の権限は不要）。
  このフォルダーを動かしたら、もう一度チェックを付け直してください。
  Windows の「設定 > アプリ > スタートアップ」でオフにした場合も、メニューから戻せます。

■ 終了
  メニューの「終了」で、キャプチャ（録画中なら録画を閉じてから）、エンジンの順に止めます。

■ ファイルの場所
  ログ        %LOCALAPPDATA%\DesktopCapture\logs（mixd.log, capd.log, tray.log。前の 4 回分も残す）
  状態        %LOCALAPPDATA%\DesktopCapture\tray-status.txt
  設定        %APPDATA%\DesktopCapture\tray.txt（mixd・capd・dc-ui に足す引数、capd = off で音声だけ）

■ 仮想カメラ
  vcam-install.cmd を実行します（管理者の確認が 1 回出ます）。外すときは vcam-uninstall.cmd。
