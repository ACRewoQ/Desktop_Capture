# P5 長時間試験（G5）

開発計画フェーズ 5 の「長時間試験（64トラック＋エフェクト、4ミックス、録画、リモコン4台）と性能目標の実測」の結果です。試験は `scripts/p5-soak.ps1`。

## 構成（2026-10-27 01:53〜04:53、Reo の PC、3 時間）

- mixd：共有モード 256 サンプル、クロック基準 UR22。64 トラック（マイク、プロセス音声、LAN 入力、仮想マイクの戻り、残り 60 本はプロセス音声）、エフェクト 152 個（全トラックに EQ・コンプ、4 本ごとにリバーブ、8 本ごとにディレイ、ローカット・ハイカット）、マスターにリミッター。出力は UR22・仮想マイク（VB-CABLE）・LAN 送信（Opus、リモコンのモニター音声）
- 2 台目の mixd（同じ PC、偽デバイス）から LAN 音声を受信
- capd：映像ミックス 4 つを同時に使用（1 = 録画 1080p60 H.264 20 Mbps、2 = 仮想カメラ、3 = リモコンのプレビュー、4 = LAN 映像送信を dc-v6-preview が受信）。ミックス 1 は仮想カメラをカメラソースとして読む
- リモート接続 4 本（エンジンの上限）：PC 上のリモコン 3 台（プレビュー＋モニター音声）と LAN 映像の受信 1 本。Surface は上限のため参加せず（Surface 単体は G4 で確認済み）
- 5 分ごとにフェーダー 8 本の変更、ミックス 3 のシーン切り替え、スナップショットの保存・呼び出し・削除

## 性能目標

| 目標 | 実測 | 判定 |
|---|---|---|
| 音声バッファ 128〜256 サンプル | 256 サンプル・64 トラック・エフェクト 152 個で音切れ 0、音声スレッドの負荷 平均 0.15 / 最大 0.32 | 合格 |
| 入力から出力までの遅延 15ms 以下（排他・ASIO） | 未試験（折り返しケーブルなし）。参考：共有モードの出力バッファ遅延 22 ms | 未試験 |
| LAN 音声の追加遅延 10〜20ms | 有線 2 台は未試験（USB-LAN なし）。シミュレーター約 10 ms、Wi-Fi 約 40 ms | 未試験 |
| 録画中の capd の CPU 5% 以下 | PC 全体の平均 1.25%・最大 1.39%（24 論理コア、1 コア換算 30%）。映像ミックス 4 つ・録画・仮想カメラ・プレビュー・LAN 映像込み | 合格 |
| プレビュー遅延 200ms 以下 | 3 台とも p50 約 42 ms、p95 約 60 ms（3 時間） | 合格 |
| リモコンの常駐メモリー 200MB 前後 | プレビュー表示しっぱなしで private 最大 243〜247 MB、3 時間で約 +6 MB | 目安どおり（G4 の見直し値） |
